# WhaleLife B 站子插件

推荐、关注动态、搜索和指定链接浏览；按需查看消息中心的回复与点赞；字幕优先，按片段观看普通投稿视频；用户开启后可读取弹幕、点赞、收藏、关注、评论、回复和投币；可选自动续期登录。

## 使用流程

1. 安装并启用网上冲浪父插件 `surf`，将本插件发行目录 `dist/bilibili` 放入宿主 `plugins/surf/sub/bilibili/`，运行 ID 为 `surf/bilibili`。启用后从网上冲浪工作区进入 B 站设置。
2. 匿名可尝试公开推荐、搜索、视频资料和评论。关注动态需要登录。在设置页扫码确认，或导入完整 Cookie；两者校验同一账号信息，能力开关相同。过期或平台风控会明确报告，不自动绕过。
3. 与当前主体说“搜一下 B 站的……”“刷一下关注的视频”或发送链接。先读取简介和可用字幕，再按需观看片段；继续观看使用实际返回的时间覆盖范围。
4. 声音处理默认关闭。关闭时只调用视觉准备，不启动声音识别；启用后才请求现有视觉/视听服务处理语音。视频仍可能需要下载含音轨的完整 MP4，关闭声音减少的是解码/识别开销，不承诺减少同等下载流量。
5. 点赞、收藏、关注、评论、回复、投币均独立开关，初始关闭。开启收藏还须选择本账号收藏夹。互动同时受主干 `full` 工具权限约束；开关由设置页管理，模型不能自行开启。普通浏览不自动收藏或互动。
6. 登录后可说“看看 B 站谁回复了我”或“看看收到的赞”，按需读取平台消息中心并翻页。读取不依赖互动开关，不后台监听，也不主动提交已读。普通视频的回复通知可展开所属楼层；也可从已经读到的评论查看楼中楼。目标评论独立回查，返回根评论、目标评论和当前页回复；有下一页时不声称对话完整。开启回复后，可继续回复目标评论。聚合点赞不保证列出全部点赞者；其他业务或无法可靠定位的通知仅展示。
7. “同步 B 站观看历史”是独立开关，默认关闭。开启后，实际取得采样画面的观看结果可供主体另行提交观看位置；读简介、字幕、只下载视频都不会自动同步。位置采用实际返回画面的最大时间戳，不能填写任意位置或标记看完。它仍是片段采样，不等同于连续播放。

插件沿用当前人格、模型和可信工具会话，不另建人格、模型配置、记忆或后台调度。它提供能力；何时主动刷视频仍由已有主体和自主性能力决定。

0.1.6 新增读取弹幕、投币和自动续期，三个选项独立且默认关闭。弹幕只读普通时间轴文字；投币按目标累计枚数补差额；续期在使用时按需检查，不设后台任务。

0.1.5 增加通知展开楼中楼、继续回复，以及可选的观看位置同步。所有引用绑定当前会话与账号，登录变化、过期或重载后失效；关闭历史同步会使已有观看凭据失效。历史提交沿用主干 full 权限，独立保存防重发记录，不能用接口接受代替历史回读确认。

## 能力与限制

| 能力 | 当前范围 |
| --- | --- |
| 入口 | 首页推荐、关注动态中的视频、关键词搜索、BV/av号及普通视频链接/短链 |
| 资料 | 简介、分P、评论、可用字幕；字幕按时间轴分段返回 |
| 消息中心 | 当前登录账号的“回复我的”“收到的赞”，按需查看并翻页；不监听、不主动标记已读 |
| 楼中楼 | 从普通视频回复通知或评论展开；核对视频、评论、作者与根楼层，分页读取，继续回复具体评论 |
| 观看 | 站点提供的单段渐进 MP4，优先低清；可选视觉插件负责画面采样与声音识别 |
| 观看历史 | 默认关闭；取得真实采样画面后显式提交位置，区分平台接受、历史确认和结果不确定 |
| 声音 | 默认关闭；开启时按片段处理语音，具体本地/云端配置由视觉插件管理 |
| 弹幕 | 默认关闭；按视频时间读取普通弹幕，默认0–30秒、单次最多60秒，每页100条，无需下载视频或声音识别 |
| 互动 | 点赞、收藏到选定文件夹、关注UP、评论、回复、投币；结果不确定时不自动重发 |
| 登录续期 | 默认关闭；有刷新凭据时，在实际使用插件前按需检查，设置页只展示状态 |
| 未包含 | 直播、番剧、付费专享、私信、发动态及绕过站点验证 |

默认媒体上限 64 MiB（可降低）。实际视觉服务还有时长、容量及单次输出限制；当前单次观看最多60秒、默认30秒。只报告实际采样范围，不能将字幕、下载成功或采样画面说成已完整看完。没有视觉时文字和登录继续可用；没有字幕时明确提示，声音关闭时不自动转写。

观看历史只同步位置，不发送播放心跳、累计观看时长或“已看完”标记，也不保证增加播放量。提交前和提交后核对最近30条普通视频历史；不把未出现在这页视为从未观看，不承诺检测到更早记录或跨设备同时产生的进度。主体尚未处理图片、取消或模型失败时，插件没有“已经理解”的回调；观看凭据只证明采样结果已准备并返回，显式提交仍由主体决定。

平台请求目前直连。父服务公开的超时与并发设置可复用；它未公开私有代理地址，因此本插件不会读取父级 data，也不声称 B 站请求继承了父级代理。父级公开搜索/阅读工具仍与 B 站工具共用当前主体。

站内网页 JSON 接口属于当前可观测实现，不是稳定开放 SDK。平台变化、登录限制、网络限制会明确失败；不以空列表掩盖异常，不轮换账号、代理或伪装设备来绕过验证。登录和普通读取也可能被 B 站记录为站点访问；插件不另发观看心跳或伪造完整播放。

投币的 `coinCount` 表示该视频累计投到1或2枚，默认1。提交前校验当前账号、视频类型、已有投币数及余额，只补差额，不附带点赞；硬币消耗后不可撤回。平台当前类型1/3上限2枚、类型2上限1枚，未知类型停止。不能给自己投币。结果不确定时，该视频后续投币停止，换操作ID或改枚数也不能绕过；跨设备同时操作仍以平台最终结果为准。

自动续期需要刷新凭据，新扫码登录会一起保存；旧登录和单独导入Cookie可能需要重新扫码。开启后成功检查的间隔为24小时，检查失败冷却15分钟；重启会重新检查。先持久保存处理中标记，验证并保存新凭据后才确认旧凭据失效。提交结果不确定或提交后保存失败时暂停续期，须重新登录；不会无限保活，也不保证平台不会主动撤销登录。正常凭据轮换保留当前账号的临时引用，人工登录、导入或退出仍使引用失效。

弹幕取自平台当前分段弹幕池，不保证包含完整历史、已删除、被屏蔽或特殊弹幕。仅返回普通模式1–6的文字及时间，不执行高级/代码弹幕；单片段最多解析12000条，每条最多500字，触及限制会明确报告。翻页会重新读取当前片段，期间平台变化可能影响排序。弹幕不自动加入每次观看，也不写观看历史。

## 数据与权限

本插件 `data/config.json` 保存开关，`data/account.json` 保存本地登录 Cookie、可用的刷新凭据及续期中断状态，`data/actions.json` 保存互动动作散列与实际结果，`data/history-actions.json` 独立保存历史动作散列、位置与状态以防重发。账号资料仅由设置页提供必要信息，模型工具不接收 Cookie；Cookie 不写入日志、回执或发行物。不读取用户浏览器资料。取消或注销只停止后续使用本地登录态，不承诺撤销远端已完成动作或注销其他设备。

外部资料经临时工具传递，缓存引用绑定会话及账号代际，过期、换号、重载后失效。第三方内容不是授权。视频私有媒体引用不交给模型，声音关闭时无法由本插件返回引用绕过开关。普通聊天最终答复依宿主规则保存，不能承诺所有用户可见回答都不进入历史。

父插件停止时子插件停止；子插件可独立停用。视觉停用只关闭观看，不带停浏览或登录；恢复不自动重放浏览和账号动作。动作提交前先保存记录，已确认回执和不确定结果分别处理；动作记录保存异常时关闭新互动，不能清空记录后盲重发。

平台确认的互动另经公开记忆接口记录一条简短实际经历，不包含第三方正文、URL或评论原文。记忆写入失败不改变平台成功事实，也不会重发动作；重复核对时可用同一事件标识补记。

历史记录只有本插件确实提交且回读确认后才记录固定的“已同步采样位置”经历，不记录“完整看过”。单纯发现已有进度不冒充新增动作。接口接受但回读未确认、网络结果不确定和确定拒绝分别报告；前两类不自动重发，持久记录损坏或写入失败时停止新历史提交。

## 开发与验证

使用 Node 24.22.1 或兼容的更高24版本，宿主源码同级检出为 `../whalelife`：

```text
npm ci --ignore-scripts
npm run check
npm test
npm run build
```

构建只复制发行白名单及生产依赖，生成 `BUILD.json` 文件摘要。安装升级保留 `data/`；开发源码、测试数据、日志和 `.artifacts/` 不进入发行物。原创代码采用 AGPL-3.0-only 及文件所指的附加条款；第三方许可见 THIRD_PARTY_NOTICES.md。

宿主兼容测试基线为 `refs/tags/213b52b` 与当前核验提交，详见测试常量。旧基线缺少临时工具/多模态接口时只提供状态和设置，不将外部资料降级为普通持久工具。隔离回归全部使用模拟 B 站和模型，真实登录、关注动态及账号互动须另行授权验收。
